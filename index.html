Lesetraining · Satzebene · Version 1.5

🔒 Datenschutz & Impressum

Lesetraining – Satzebene: fünf Niveaus mit jeweils sieben Übungen zum sinnentnehmenden Lesen. Die Silben sind abwechselnd blau und rot markiert.

🗄️ Datenspeicherung

Ergebnisse werden während der Übung nur auf diesem Gerät verarbeitet. Für das Speichern oder Teilen des Ergebnisprotokolls wird ein Name eingegeben, der im Protokoll und im Dateinamen steht. Über das Teilen-Menü des Geräts kann das Protokoll zum Beispiel per AirDrop gesendet werden. Die App kann nach dem ersten vollständigen Laden offline genutzt werden.

☁️ Hosting & Server (GitHub Pages)

Bei Bereitstellung der App über GitHub Pages (GitHub Inc., USA) können beim Online-Abruf Server-Logs mit IP-Adresse, Zeitstempel und Browser-Typ anfallen. Diese werden von GitHub verwaltet.

Offline-Nutzung: Nach dem vollständigen ersten Laden speichert der Browser die App lokal (Service Worker / Cache). Für die Übungen ist anschließend keine Internetverbindung erforderlich. Bei einem späteren Online-Aufruf kann die App auf Aktualisierungen prüfen.

Datenschutzerklärung von GitHub: docs.github.com/privacy
